# Image prompts and provenance

Created 2026-10-17 with the **built-in image generation tool**, using the **imagegen skill**. No CLI/API-key fallback was used. Requested landscape size: 1536 × 1024; opaque backgrounds. All selected final PNGs are stored beside this document.

The images are interface proposals. Numeric geometry, physical recipes and the written specification take precedence over generated perspective, small labels and schematic fittings. All outputs were visually inspected; correction passes addressed post mounting, the continuous wooden core, and unsupported material claims/stock labels.

The existing CanFactory interface supplied the cream/terracotta palette and typography. The original first sheet became the style reference for sheets 02–05. No IKEA artwork or retailer product photographs were copied into these images.
