# AI rubber duck generation prompts

Generated with the built-in `image_gen` tool using the imagegen skill. Each PNG is a separate generation with `transparent_background: false`; no CLI fallback or source image was used.

These are visual concepts for later OpenSCAD work, not measured geometry. Codex uses a terminal-inspired `>_` face. All brand interpretations are unofficial concepts.
