# Magnetic cat toy

This is an **original CanFactory design**, hand-authored directly in
`generator.scad`. It is not derived from an STL or third-party model. There is no
source STL or `reference/` directory.

The model source and generated geometry are licensed under **Creative Commons
Attribution 4.0 International (CC BY 4.0)**:
<https://creativecommons.org/licenses/by/4.0/>. Credit: CanFactory.

Magnet seats use the repository parts library's sourced supermagnete disc
products, including their stated dimensional tolerances. Cover fastening uses
library ISO 4762 M3 × 8 screws and ISO 4032 M3 nuts. Product dimensions do not
make this model a manufacturer-endorsed product.

The fit convention (per-side clearance plus independently tuned detent
engagement) follows the repository's cigarette-case and litter-shovel patterns;
the geometry is newly authored. These model terms do not relicense unrelated
application code.
