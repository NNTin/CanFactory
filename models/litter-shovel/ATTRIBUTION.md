# Litter shovel

This model is an **original CanFactory design**: a cat-litter sifting scoop with a matching
container that a liner bag fits into, and a handle that clips the scoop onto the container for
storage. Its three generators (`container.scad`, `scoop.scad`, `handle.scad`) were written in
OpenSCAD for this application from measurements of a real-world object. No third-party model
source or mesh is included or redistributed, so there is no `reference/` folder to preserve.
