# Magnetic lighter keychain

This model is an **original CanFactory design**. It is not derived from any third-party
model: `generator.scad` was written directly in OpenSCAD for this application, so there
is no `reference/` folder with an original STL or source to preserve.

## What it is sized for

The sleeve is fitted to the BIC Mini lighter (J25), as the parts library models it
(`bic-j25-mini-lighter`: BIC's own 62 × 22 × 11 mm, with the oval plan estimated from
photographs). The magnet cavities and the eyelet are sized from the chosen parts-library
magnet and split ring. Only these listed sizes are used.
