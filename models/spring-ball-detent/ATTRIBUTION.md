# Spring ball detent

This model is an **original CanFactory design**. It is not derived from any third-party
model: `generator.scad` was written directly in OpenSCAD for this application, so there
is no `reference/` folder with an original STL or source to preserve.

## Parts it is sized for

The bore, lip, spring seat and set-screw hole are sized from the parts library's
published dimensions: ISO 3290-1 / DIN 5401 grade G100 steel balls (largest values),
Gutekunst compression springs (each article's data) and ISO 4026 set screws. The body's
thread is the ISO 261 coarse thread with the ISO 68-1 basic profile. The standards
themselves are not reproduced.

It performs the same role as bought spring plungers with a ball, such as Otto Ganter's
GN 615 and GN 615.3, whose published sizes were compared with it, but it is not a copy of
any of them: it is a printed body generated round a chosen ball and spring, closed by a
printed press cap or a set screw instead of a rolled nose.
