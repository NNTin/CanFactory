# Printed screen hook

This model is an **original CanFactory design**. It is not derived from any third-party
model: `generator.scad` was written directly in OpenSCAD for this application, so there
is no `reference/` folder with an original STL or source to preserve.

## Parts it is sized for

The screw holes and countersinks are sized from the parts library's published dimensions
of DIN 7997 countersunk wood screws (largest head values), with the clearance-hole
allowances DIN EN 20273 gives for M4 and M5. The standards themselves are not reproduced.

It performs the same role as bought insect-screen hooks (Einhängefedern, such as
Windhager's 03651 set in the parts library), but it is not a copy of any of them: it is a
printed section generated for one window's lip and seal gap rather than a bent steel strip.
